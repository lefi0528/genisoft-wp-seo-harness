# Templates & Configuration Library

All templates are located in the `templates/` directory of the repository:

| File | Purpose | Target Agent |
|---|---|---|
| `templates/AGENTS.md` | Operating rules, invariants, and Definition of Done. | All agents |
| `templates/CLAUDE.md` | Fast-path command reference and shortcuts. | Claude Code / Cursor |
| `templates/seo_tasks.json` | 6-phase atomic technical SEO backlog. | Autonomous task runners |
| `templates/progress.md` | Session state log preventing context amnesia. | All agents |
| `templates/session-handoff.md` | Session closure note for multi-developer handoff. | All agents |
