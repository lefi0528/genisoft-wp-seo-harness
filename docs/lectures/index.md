# Curriculum & Theory Overview

The Genisoft WP SEO Harness course is divided into **10 progressive lectures**. Each lecture answers one architectural question about governing AI agents inside WordPress environments.

```
┌──────────────────────────────────────────────────────────────────┐
│                     THE 5-PHASE LEARNING PATH                    │
│                                                                  │
│  Phase 1: UNDERSTAND THE PROBLEM (L01 - L02)                     │
│  Phase 2: THE 5 SUBSYSTEMS & INSTRUCTIONS (L03 - L04)            │
│  Phase 3: STATE & SESSION CONTINUITY (L05 - L06)                 │
│  Phase 4: SCOPE CONTROL & VERIFICATION GATES (L07 - L08)         │
│  Phase 5: ENTERPRISE KNOWLEDGE GRAPH & RUNTIME GUARDS (L09 - L10)│
└──────────────────────────────────────────────────────────────────┘
```
